# Provenance and extraction record

## Source

The original owned source was a small deterministic Python simulation at:

```text
Edilec shared visual library / _tools / retry_sim.py
```

It was written to support an accurately labelled illustration of retry storms.
The source compared fixed exponential delay with full jitter in one hard-coded
scenario.

## What was generalized

- hard-coded constants became validated configuration;
- fixed and full-jitter modes became four documented strategies;
- events gained stable client identities and independent random streams;
- terminal outcomes distinguish completion, retry exhaustion, and horizon
  timeout;
- bucket-level reports gained a versioned JSON envelope and CSV output;
- the script became an importable typed package with a CLI and tests.

## What was excluded

- Edilec logos, fonts, colours, and other identity assets;
- rendered charts, images, videos, captions, and social publishing records;
- website and publishing code;
- production traffic, customer, credential, and infrastructure data; and
- third-party code.

The repository contains a simulation only. All included example results are
generated by the checked-in implementation from explicit parameters and are
described as simulated.

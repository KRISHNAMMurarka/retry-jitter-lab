# Support

Use [GitHub Issues](https://github.com/KRISHNAMMurarka/retry-jitter-lab/issues)
for reproducible bugs and focused feature requests.

This experimental project does not include a service-level agreement or
production capacity-planning support. Questions about applying the model to a
specific production system may require a separate architecture and reliability
review.

Suspected vulnerabilities belong in the private route described in
[SECURITY.md](./SECURITY.md).

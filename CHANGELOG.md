# Changelog

All notable changes are recorded here. The project follows semantic versioning
after its initial experimental release.

## Unreleased

### Added

- Added a manually dispatched, approval-gated release workflow that verifies
  immutable tags and produces checksummed wheel and source distributions.

## 0.1.0 - 2026-08-24

### Added

- Deterministic bucketed outage-recovery simulation.
- No-jitter, full-jitter, equal-jitter, and decorrelated-jitter strategies.
- Typed Python API and command-line interface.
- Text, versioned JSON, and bucket-level CSV reports.
- Tests, documentation, provenance record, and repository governance files.
